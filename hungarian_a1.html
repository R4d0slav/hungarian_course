Key Pronunciation Rules

Essential
📌 The 8 Rules

1. Stress is ALWAYS on the first syllable. No exceptions.
2. Every letter is pronounced — no silent letters.
3. S = "sh" (like "show"). For English "s", use SZ.
4. J = "y" (like "yes"). So "Jó" sounds like "Yoh". LY is identical.
5. Long vowels (with accent) are held about twice as long.
6. Double consonants (ll, ss, tt...) are held twice as long too. Anna → "AHN-nah".
7. No diphthongs. Each vowel is a pure, separate sound. "Ei" = two distinct vowels.
8. GY is tricky — a soft "dj" sound, like the "d" in British "duke" (dyook).

Szia → "SEE-yah" (not "SZ-ee-ah")
Köszönöm → "KEU-seu-neum" (stress on first syllable)
gyerek → "DJEH-rek" (GY = soft dj)

Vowel Harmony

Core Grammar Concept
🎵 What is vowel harmony?

Hungarian suffixes (word endings) change depending on the vowels in the root word. Words with back vowels (a, á, o, ó, u, ú) take one form of suffix; words with front vowels (e, é, i, í, ö, ő, ü, ű) take another. You'll see this throughout the course!

ház → "house" (back vowel á) → házban = "in a house"
kert → "garden" (front vowel e) → kertben = "in a garden"

📝 Adjectives Come Before Nouns

Just like English, Hungarian adjectives go before the noun. The great news: no gender agreement — color words never change their ending based on the noun!

piros ház → "red house"  |  kék ég → "blue sky"  |  zöld fa → "green tree"
A ház piros. → "The house is red." (adjective used as predicate)
💡 Milyen? — "What color / What kind?"

Milyen? is the adjective question word: "What kind?" or "What color?"

Milyen szín? → "What color?"  |  Milyen a macska? → "What is the cat like?"
Milyen a ház? → Piros. → "What's the house like?" → "Red."

Dark & Light Shades

Sötét & Világos
🌗 Modifying colors: sötét (dark) · világos (light)

Simply place sötét (dark) or világos (light) directly before the color word — no hyphen, no changes to the color word itself. Very straightforward!

sötétkék → dark blue  |  világoskék → light blue
sötétzöld → dark green  |  világoszöld → light green
sötétbarna → dark brown  |  világosszürke → light grey
sötétvörös → dark red (vörös = a darker/more intense red than piros)

Verb + Infinitive Patterns

Extremely useful combos
🔗 Modal-like constructions

Hungarian uses the conjugated verb + infinitive to express wanting, liking, and ability — no special "modal verb" form needed.

Szeretek + infinitive → "I like to..." / "I love..."

  Szeretek olvasni. — I like to read.

Tudok + infinitive → "I can..." / "I know how to..."

  Tudok magyarul beszélni. — I can speak Hungarian.

Akarok + infinitive → "I want to..."
  Akarok tanulni. — I want to study.
  Akarok menni. — I want to go.

Kell + infinitive → "I need to..." / "One must..."
  Mennem kell. — I need to go. (lit. "Going-my is-needed.")

Nouns & the Accusative

The accusative case marks the direct object — what's receiving the action. Learn this and you can say "I see the house," "I eat bread," and much more.

⏱ ~22 min
📦 -t ending
🔧 Vowel harmony

Articles: a / az / egy

Definite & Indefinite
📌 Hungarian Articles

a = the (before consonants): a ház = the house
az = the (before vowels): az alma = the apple
egy = a / an: egy könyv = a book

No plural definite article — just pluralize the noun:
a házak = the houses  |  a könyvek = the books

The Accusative Case

Direct object marker
📐 Three Rules for Adding -t

1. Ends in vowel → just add -t:
  alma → almát  |  autó → autót  |  kávé → kávét

2. Ends in consonant → linking vowel + t (vowel harmony!):
  Back vowels (a,á,o,ó,u,ú): add -at → ház → házat
  Front vowels (e,é,i,í,ö,ő,ü,ű): add -et / -öt → könyv → könyvet

3. Ends in sonorant (-l,-n,-r,-ny,-j) → just -t:
  lány → lányt  |  asztal → asztalt

Látom a házat. → "I see the house."
Eszem az almát. → "I'm eating the apple."
Olvasok egy könyvet. → "I'm reading a book."

Definite vs. Indefinite

A key Hungarian distinction
💡 Hungarian verbs "know" what they're acting on

Hungarian has two conjugation sets for most verbs — indefinite (used with "a/an" objects or no article) and definite (used with "the" objects). At A1, just know this distinction exists. You've been using the indefinite forms.

Indefinite: Eszem egy almát. — I'm eating an apple. (object = "a/an")
Definite:   Eszem az almát. — I'm eating the apple. (object = "the")

The difference shows in the verb: eszem vs eszem (same here, but see: látok vs látom)
Látok egy házat. (indef)  vs  Látom a házat. (def)

Core Sentence Patterns

Click to hear the example
📝 Hungarian Word Order

Default order is Subject → Object → Verb (SOV), but it's flexible because case endings show function. The most emphasized element goes immediately before the verb.

Én kenyeret eszem. = I (am eating) bread. (neutral)
Kenyeret eszem. = It's bread (that) I'm eating. (emphasis on bread)

In questions, the question word takes the focus position — right before the verb:
Mikor jössz? = When are you coming?  |  Hol van a kulcs? = Where is the key?

Negation — "Nem" & "Nincs"

Key Grammar

Use nem to negate verbs and adjectives. Use nincs (not-have/not-exist) to negate possession and existence.

✏️ Negation Rules

nem + verb: Nem tudom. = I don't know.  |  Nem eszem húst. = I don't eat meat.
nem + adjective/noun after van: Nem vagyok fáradt. = I'm not tired.
nincs + possessive: Nincs pénzem. = I don't have money. (lit. "there is no my-money")
nincs + noun: Nincs tej. = There is no milk.

Time Expressions

Grammar
The forward-reference rule

Fél [next hour] = half past [hour-1]. Negyed [next hour] = quarter past [hour-1]. Háromnegyed [next hour] = quarter to [hour]. Add -kor to say "at" a time.

Grammar
The instrumental suffix -val/-vel

To say "by [transport]", add -val/-vel (back/front harmony). The consonant assimilates: if the noun ends in a consonant, that consonant doubles. E.g.: busz + val → busszal; vonat + tal → vonattal.

Activity nouns with -ás/-és

Hungarian forms activity nouns by adding -ás/-és to the verb stem: úszni → úszás (swimming), futni → futás (running). To say "I like [activity]", use: Szeretek + infinitive.

Health Phrases

Grammar
Expressing pain: Fáj a [body part + possessive]

To say a body part hurts: Fáj a fejem. (My head hurts.) The body part takes a possessive suffix: fej + -em = fejem. This pattern works for every body part.
